# Sticker Maker — Privacy Policy

Public privacy policy for the Android app **Sticker Maker**
(`hk.android.free.truesticker.stickermakerforwhatsapp.stickercreater`), published by HashtagHK.

**Live:** https://hashtaghk.github.io/stickermaker-privacy/

This repository exists solely to serve that page over GitHub Pages, so the Play Console listing
has a stable public URL.

One repository per app is deliberate: each policy stays independently transferable if an app
changes hands, and an accident here (rename, deletion, flipping to private) cannot take down
another app's privacy link. A shared repository would make every listing fail at once.

## Contents

- `index.html` — the page served by GitHub Pages
- `privacy-policy.md` — the same content in Markdown

## Updating

Edit `index.html` (and `privacy-policy.md` to match), commit, push. GitHub Pages redeploys
automatically. Update the "Last updated" date whenever the content changes.

Contact / data-deletion requests: admin@hashtaghk.com
